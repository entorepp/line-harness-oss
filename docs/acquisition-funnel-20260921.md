# Unified acquisition funnel — 2026-09-21

Owner requested separate counts for request receipt, rendered page, interaction, and saved submission. Initial scope is the public Flat Travel site and Accessible Japan form 9ab583b2-e42e-4ca2-bcb9-13a3c59f5477. Existing survey implementations outside this form are not instrumented by this change.

## Definitions
- Every non-prefetch document GET is recorded before rendering, including failed rendering. This is an HTTP receipt, not proof of a human click on Accessible Japan. Existing tagged links work without replacement.
- Optional /go/accessible-japan on flat-travel.com and /go/aj-form on liffform-studio.pages.dev record a separate redirect receipt before the landing page. Partner must adopt these URLs for this extra indicator. Existing partner links were not edited.
- page_visible requires a foreground document, the main form/site container, and two animation frames; form fields must exist. Receipt without visible acknowledgement is unconfirmed display, not proven abandonment.
- Trusted interaction events record no entered values. Each form field/step records at most once per page. Link clicks record each click with an idempotency UUID; retrying delivery does not multiply counts.
- submit_success is server-only, after the existing intake confirms save. A 200 with an unsuccessful body cannot convert. No customer submission is generated by deployment.
- Random first-party HttpOnly af_visit cookie lasts 30 minutes; reloads are separate request rows in the same visit. UTMs normalize Accessible Japan aliases. Missing UTM is unattributed, never inferred as direct.
- Reports cohort by visits started within the selected UTC interval, showing subsequent events received by query time. First-party clicks, UTM requests, and visit-stage totals are separate units. Tests marked af_test=1 or aj_test=1 inherit test status and are excluded.

Unauthenticated API access must return 401. The site cannot serve reports. No new account, credential, background job or provider API.
